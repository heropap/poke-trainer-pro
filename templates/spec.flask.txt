================================================================================
                         项目规格说明 (Project Spec)
================================================================================

【项目名称】
blog-platform

【项目描述】
一个博客平台，包含文章管理、用户系统、Markdown 渲染，
使用 Python Flask + SQLAlchemy + SQLite 构建。

================================================================================
                              技术栈
================================================================================

框架:         flask
语言:         python
包管理器:      pip
测试框架:      pytest
数据库:        SQLite (通过 Flask-SQLAlchemy)

================================================================================
                            开发环境
================================================================================

启动命令:      flask run --debug --port 5000
端口:          5000
健康检查URL:   http://localhost:5000/health
启动超时:      15秒
测试命令:      pytest -v

================================================================================
                         功能清单 (按优先级排序)
================================================================================

--- 功能 1 [infrastructure] 优先级: 0 ---
描述: Flask 项目架构搭建
步骤:
  - 创建虚拟环境，安装 flask, flask-sqlalchemy, flask-migrate
  - 使用应用工厂模式 (create_app)
  - 创建目录结构 (app/, app/models/, app/routes/, app/templates/, tests/)
  - 配置 SQLAlchemy + SQLite
  - 添加 /health 端点
  - 创建基础 HTML 模板 (base.html)

--- 功能 2 [functional] 优先级: 1 ---
描述: 用户注册与登录
步骤:
  - 创建 User 模型 (id, username, email, password_hash)
  - 安装 Flask-Login 管理会话
  - 创建注册页面和路由
  - 创建登录/登出页面和路由
  - 添加密码哈希 (werkzeug.security)
  - 编写认证测试

--- 功能 3 [functional] 优先级: 2 ---
描述: 文章 CRUD 功能
步骤:
  - 创建 Post 模型 (id, title, content, author_id, created_at, updated_at)
  - 创建文章列表页 (首页)
  - 创建文章详情页
  - 创建发布/编辑文章页面 (需登录)
  - 添加删除文章功能 (仅作者可删)
  - 编写文章 CRUD 测试

--- 功能 4 [functional] 优先级: 3 ---
描述: Markdown 渲染与代码高亮
步骤:
  - 安装 markdown, pygments
  - 文章内容支持 Markdown 语法
  - 添加代码块语法高亮
  - 创建 Jinja2 过滤器渲染 Markdown
  - 编写 Markdown 渲染测试

--- 功能 5 [ui] 优先级: 4 ---
描述: 页面美化与响应式设计
步骤:
  - 集成 Bootstrap 5 或 Tailwind CSS
  - 统一页面风格 (导航栏、卡片布局、排版)
  - 移动端适配
  - 添加分页组件

--- 功能 6 [testing] 优先级: 5 ---
描述: 完整测试套件
步骤:
  - 为所有路由编写测试
  - 创建测试 fixtures (conftest.py)
  - 添加 pytest-cov 覆盖率
  - 确保测试数据库隔离
