================================================================================
                         项目规格说明 (Project Spec)
================================================================================

【项目名称】
todo-app

【项目描述】
一个全栈 Todo 应用，包含用户认证、任务管理、响应式 UI，
使用 Next.js + TypeScript + Tailwind CSS 构建。

================================================================================
                              技术栈
================================================================================

框架:         nextjs
语言:         typescript
包管理器:      npm
测试框架:      jest
数据库:        SQLite (通过 Prisma ORM)

================================================================================
                            开发环境
================================================================================

启动命令:      npm run dev
端口:          3000
健康检查URL:   http://localhost:3000
启动超时:      30秒
测试命令:      npm test -- --passWithNoTests

================================================================================
                         功能清单 (按优先级排序)
================================================================================

--- 功能 1 [infrastructure] 优先级: 0 ---
描述: 项目基础架构搭建 - Next.js + TypeScript + Tailwind CSS
步骤:
  - 使用 TypeScript 模板初始化 Next.js 项目
  - 安装并配置 Tailwind CSS
  - 建立目录结构 (components/, pages/, lib/, types/)
  - 创建基础布局组件 (Header + Footer)
  - 添加基础首页

--- 功能 2 [infrastructure] 优先级: 1 ---
描述: 数据库搭建 - Prisma + SQLite
步骤:
  - 安装 Prisma 并用 SQLite 初始化
  - 在 schema.prisma 中定义 User 和 Todo 数据模型
  - 运行首次数据库迁移
  - 创建 Prisma 客户端单例 (lib/prisma.ts)

--- 功能 3 [functional] 优先级: 2 ---
描述: 用户认证 - NextAuth.js
步骤:
  - 安装并配置 NextAuth.js (credentials provider)
  - 创建注册 API 路由和表单页面
  - 创建登录页面
  - 在 layout 中添加 Session Provider
  - 创建认证中间件保护路由

--- 功能 4 [functional] 优先级: 3 ---
描述: Todo CRUD 操作
步骤:
  - 创建 API 路由: GET/POST /api/todos, PUT/DELETE /api/todos/[id]
  - 构建 TodoList 组件 (添加、切换完成状态、删除)
  - 添加行内编辑功能
  - 实现按状态筛选 (全部/进行中/已完成)
  - 连接 Prisma 实现数据持久化

--- 功能 5 [ui] 优先级: 4 ---
描述: 响应式设计 + 深色模式
步骤:
  - 实现移动端/平板/桌面端响应式布局
  - 添加深色模式切换 (localStorage 持久化)
  - 检测系统颜色偏好
  - 为所有组件适配浅色/深色主题

--- 功能 6 [testing] 优先级: 5 ---
描述: 完整测试套件
步骤:
  - 为 Todo API 路由编写单元测试
  - 为 TodoList 组件编写组件测试
  - 为认证流程编写集成测试
  - 添加测试覆盖率报告
