Status: completed
Notes: 解决了卡牌导入成功后无法在对战系统中使用的核心问题。

实现内容:
- deck-storage.ts: localStorage 持久化服务，支持保存/读取/删除卡组，提供 getDeckCardIds() 作为对战系统的主要接口
- DeckContext.tsx: React Context 全局状态管理，DeckProvider 包裹在根布局中，跨页面共享卡组数据
- engine/game-state.ts: 核心游戏状态类型（GameState, Player, Zone, GameCard），工厂函数和事件日志系统
- engine/zones.ts: 区域管理工具（洗牌/抽牌/移动/查找），Fisher-Yates 洗牌算法
- engine/battle-setup.ts: 卡组→对战桥接，loadDeckCards() 将存储的卡组 ID 解析为 GameCard 实例，initializeGame() 完成完整的对战初始化（洗牌→抽牌→奖励卡→开始回合）
- BattlePageClient.tsx: 对战页面客户端组件，支持卡组选择/对战初始化/游戏状态展示/事件日志
- 更新 DeckImport 和 DeckPageClient：导入后自动保存到 localStorage，显示已保存卡组列表
- 修复 CardSearch 组件 React 19 兼容性问题（useMemo→useEffect 避免渲染期间 setState）

Feature: 对战 UI - PTCG Live 风格 UX 交互
Status: completed
Notes: 修复了训练师卡无法点击使用的根因，并实现了 PTCG Live 风格的完整交互系统。

根因分析:
- @dnd-kit 的 useDraggable hook 在外层 div 展开 {...listeners}，拦截所有 pointer 事件（onPointerDown）
- 导致内层 VisualCard 的 onClick 永远无法触发
- Session 10 添加的点击使用功能从未生效

修复与实现:
1. BattleBoard.tsx — PointerSensor + activationConstraint: { distance: 5 }
   - 普通点击不会移动 5px → onClick 正常触发
   - 拖拽手势自然超过 5px → 拖拽仍有效
   - 这是 @dnd-kit 官方推荐的点击+拖拽共存方案

2. BattleBoard.tsx — 选择状态 + 目标选择模式
   - selectedCardId/targeting 状态管理
   - computePlayableCardIds(): 计算当前回合可用的卡牌
   - handleMenuAction(): 路由卡牌动作（直接使用/进入目标选择模式）
   - handleTargetClick(): 目标选择完成后执行动作
   - Escape 键取消选择，回合切换自动重置选择

3. ActionMenu.tsx（新文件）— 浮动操作菜单
   - 根据卡牌类型显示不同操作: Item→使用, Supporter→使用, Tool→装备, Basic→放置, Stage→进化, Energy→附加
   - 效果未注册的训练师卡: 橙色 "!" 标记 + 警告文字

4. Hand.tsx — 可用/不可用/选中视觉状态
   - 可用卡: 黄色微光环，hover 上提
   - 不可用卡: 半透明 + 去饱和 + 禁止光标
   - 已选中卡: 大幅上提 + 蓝色高亮环
   - 目标选择模式: 手牌全部变暗

5. ActiveSpot.tsx + BenchSpot.tsx — 目标选择支持
   - 新增 isTargetable + onTargetClick props
   - 有效目标: 绿色发光边框 + 脉冲动画

6. Toast 通知系统
   - 效果未实现 → 橙色警告，操作失败 → 红色错误，3 秒消失
