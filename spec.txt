Pokemon TCG · v0 — 精简规格

本规格只描述 v0 范围。完整 PTCG 规则随 feature 落地逐步补全。

================================================================
项目目标 (v0)
================================================================
打造一个桌面浏览器版的 Pokemon TCG 单人 PvE 体验，参考 PTCG Live
的横向战场布局与视觉风格，从中国区域官方发布的三套大师卡组开始：

  1. 喷火龙 ex 大师卡组
  2. 密勒顿 ex 大师卡组
  3. 沙奈朵 ex 大师卡组

后续版本逐步扩充更多卡组与机制。本版本不实现联机对战、不实现音效、
不实现移动端响应式 — 这些都留给 v0 之后。

================================================================
技术栈
================================================================
- Next.js 16 (App Router) + React 19 + TypeScript 5
- Tailwind CSS 4
- 状态管理：useReducer（游戏状态） + Zustand（UI 状态）
- 拖拽：@dnd-kit/core
- 动画：framer-motion
- 测试：Jest + React Testing Library
- 部署：Vercel / Docker（保留旧 Dockerfile / vercel.json）

================================================================
核心引擎设计要点
================================================================
- 纯 reducer：(state, action) => state'，状态不可变
- 同步驱动 + 中断 prompt：reducer 推进遇到 prompt 暂停，等外部应答
- 卡牌效果 = TS 函数：(ctx) => Action[]，不上 DSL 不上 LLM 抽取
- AI = 启发式：能进化就进化、能挂能量就挂、能搜就搜、能攻击就打最高伤害
- 副作用（动画 / 声音）通过 reducer 返回的 log 派生，不入引擎

GameState 字段（精简版）：
  players: [PlayerState, PlayerState]   // [self, opponent]
  activePlayer: 0 | 1
  phase: 'setup' | 'draw' | 'main' | 'attack' | 'between' | 'gameOver'
  turnNumber: number
  stadium: GameCard | null
  pendingPrompt: Prompt | null
  log: GameEvent[]
  winner: 0 | 1 | null

PlayerState：
  deck / hand / active / bench(5) / prizes(6) / discard / lostZone
  hasPlayedSupporter / hasAttachedEnergy / retreatedThisTurn

GameCard：
  uid / cardId / damage / attachedEnergy / attachedTool / evolutionStack
  status / markers

================================================================
UI 视觉规范
================================================================
- 主色：深暗紫蓝渐变 linear-gradient(135deg, #0d0e26, #1a0d3a, #0f1a3a)
- 强调色：按属性 6 色调色板（火 / 水 / 草 / 电 / 超 / 钢 / 恶 / 格斗）
- 活跃 Pokemon 光晕：box-shadow + drop-shadow + pulse 呼吸 keyframe
- 稀有卡 holographic：mask-image 渐变 + mix-blend-mode: color-dodge
- 字体：系统字体栈，数字用 Inter 或等宽

布局（自上而下视角，self 在下）：
  rows 1-3   对手 prize / bench / deck-discard
  rows 4-5   对手 active
  row 6      Stadium（中央接缝）
  rows 7-8   己方 active（光晕）
  rows 9-10  己方 prize / bench / deck-discard
  rows 11-12 HandFan
  右侧悬浮：ActionLog / TurnTimer / OptionsMenu
  中央悬浮：PromptStack / CardZoom / FX 层

================================================================
开发命令
================================================================
- 开发：cd app && npm run dev          (port 3000)
- 测试：cd app && npm test
- 构建：cd app && npm run build
- 健康检查：curl localhost:3000/api/health
- 端到端验证：bash init.sh             (root 目录运行)
